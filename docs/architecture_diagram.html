The Problem

A sensor lasts 14 days and costs ₹4,200. So a patient wears it once, gets a report, and is treated from that report for months. Nobody tells the doctor how old the report has become.

The Core Concept — "The Reveal"
Chhaya's estimate (purple with 80% band) is drawn without the sensor. Then the real sensor trace (teal) slides over it. The doctor sees where the shadow was right — and where it missed.

Evaluation Pipeline
1

Split by Patient, Never by Row

Half tunes settings. Half scored once. --confirm flag on committed code.

2

Write Bars Before the Run

Success criteria registered in PREREGISTRATION.md with dated amendments. No moving goalposts.

3

Calibrate on k Days of Sensor

MAP fit of 7 params. Record sets prior. Tested k=3, 5, 7.

4

Simulate the Shadow

50% ODE physiology + 50% patient's average day. Laplace ensemble → 80% band.

5

Assimilate Fingersticks

Kalman filter with fading deviation (τ=120min). RTS smoother for retrospective report.

6

Detect Report Staleness

CUSUM of standardised surprises. AUROC 0.82 for drift detection.

7

Publish Misses With Passes

Every result → JSON. Tests check each figure value against claim wording. Numbers and words cannot drift.

Clinical Dashboard — Three Screens, Ten-Second Read
Built to be read by a doctor in a 4–5 minute consult. Runs offline from pre-computed JSON. Nothing is fitted while it runs. No dose advice. No alarm. An estimate is never drawn without its band and the word "estimated".

Design Principles — What Separates This From a Model Validated on Its Own Simulator
🔒
No Leakage
Every feature builder tested: change the hidden sensor, check nothing else moves
🧑‍⚕️
Split by Patient
Development / held-out. Scored once. --confirm on committed code
📝
Bars Written First
Pre-registered criteria with dated amendments. No moving the goalposts
🪟
Misses Published
A failed fit is a row with an error, not a dropped patient. 4 missed bars on every page
🔄
One-Command Repro
Every result regenerated by a single command. Results committed, code committed
🏷️
Synthetic Labelled
"Mrs. R." is simulated and labelled so on screen. No genetic markers in either dataset
